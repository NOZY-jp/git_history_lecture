# C0de × RCC 合同勉強会: Git & GitHub 入門編

## 🌟 ようこそ！
本リポジトリは、**C0de（名古屋工業大学）** と **RCC（立命館大学）** による合同勉強会で使用する公式リポジトリです。
本セッションの前半パートである「Git / GitHub の使い方講座」において、実際に手を動かしながら学ぶためのワークスペースとして提供しています。

---

## 🛠️ 事前準備
本講義では、GUIツールを用いて直感的にGitを操作するため、**GitHub Desktop** の使用を推奨しています。
リポジトリを自身の環境にクローン（複製）するには、以下の手順に従ってください。

1.  本ページ右上の緑色のボタン **`<> Code`** をクリックする。
2.  メニューから **`Open with GitHub Desktop`** を選択する。
3.  自動的にアプリが起動するため、保存先を確認してクローンを完了させる。

---

-   GitHubを用いた共同開発のワークフロー
